# 스도쿠

빈칸에 1~9를 채우는 숫자 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 난이도 3단계: 쉬움(힌트 40개) · 보통(32개) · 어려움(26개)
- 문제는 매번 새로 만들고, 정답이 딱 하나뿐인 문제만 낸다
- 틀린 숫자는 3번까지, 힌트는 한 판에 3번 (점수가 깎인다), 메모로 후보 숫자를 적어 둘 수 있다
- 하던 판은 자동 저장되어 나중에 이어할 수 있다

`index.html` 을 그대로 열면 된다. 문제 만들기·풀이는 `logic.js`, 화면·입력은 `game.js`.
